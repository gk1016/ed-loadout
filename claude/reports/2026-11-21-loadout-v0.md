## Deviations from the plan

- **apply ordering.** The plan says backup, write profile files, then apply overrides.
  apply computes the overridden contents in memory first and writes each file once, so
  an absent element aborts before the backup or any write. The end state is the same
  as the plan's order; the failure case leaves the Options dir untouched.
- **ssaa with more than one `Graphics/Custom.*.fxcfg`** is an error. The plan says "the
  profile's `Graphics/Custom.*.fxcfg`" and the fixture has one. See needs-Graham.
- **Exit codes.** The plan fixes 0/1 for diff and check-binds and 2 for the refusal.
  Errors exit 3. clap's usage errors are also 2.
- **Deps.** walkdir is used only to list a profile's `files/`. serde is not used
  (profile.toml is read as a `toml::Table`), so it is not a dependency.
- **diff** keys a repeated root child as `Name[2]`, `Name[3]` (Codex finding 5). The
  three flat files have no repeated names today.
- **check-binds** `--binds` given as a relative path that does not exist from the cwd is
  taken relative to the Bindings dir.
- The prompt's "SPA, migrations, scripts" and "local engine" do not apply: this plan is
  a CLI with no engine. Nothing was stood up, so nothing needed tearing down.
